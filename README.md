# Эмулятор командной оболочки

Практическая работа по конфигурационному управлению.
Вариант №8.

## Описание

Эмулятор командной оболочки UNIX-подобной операционной системы
с графическим интерфейсом.

## Текущее состояние

Подготовлена структура проекта и проверочный запуск.
Команды оболочки пока не реализованы.

## Среда разработки

- Windows
- Python 3.14.3 из MSYS2
- Tkinter
- PyCharm

## Подготовка окружения

```powershell
python -m venv .venv
```

## Запуск

Из корневой папки проекта:

```powershell
.\run.bat
```
