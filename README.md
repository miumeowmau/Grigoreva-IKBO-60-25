# Эмулятор командной оболочки

Практическая работа по конфигурационному управлению.
Вариант №8.

## Описание

Графический эмулятор командной оболочки UNIX-подобной ОС.

Реализован минимальный прототип первого этапа:
ввод команд, разбор аргументов с кавычками, сообщения об ошибках,
заглушки ls и cd, завершение приложения командой exit.

Настоящая работа с виртуальными файлами и папками пока не реализована.

## Среда разработки

- Windows.
- Python 3.14.3 из MSYS2.
- Tkinter.
- PyCharm.

Сторонние библиотеки не требуются.
Используются стандартные модули Python.

## Структура проекта

- src/main.py — исходный код приложения.
- tests — каталог для будущих автоматических тестов.
- run.bat — скрипт запуска для Windows и Python из MSYS2.
- .gitignore — исключения для Git.
- README.md — описание проекта.

## Подготовка и запуск

Команды выполняются из корневой папки проекта.

Создание виртуального окружения:

```powershell
python -m venv .venv
```

Проверка Tkinter в окружении:

```powershell
.\.venv\bin\python.exe -m tkinter
```

Запуск приложения:

```powershell
.\run.bat
```

Отдельная сборка не требуется.

Скрипт использует расположение интерпретатора MSYS2:
.venv/bin/python.exe.

Для запуска через PyCharm необходимо выбрать этот интерпретатор
в настройках проекта и запустить src/main.py.

## Использование

Введите команду в нижнее поле.
Для отправки нажмите Enter или кнопку «Отправить».

Введённая строка и результат появляются в области вывода.
Пустой ввод и строки из пробелов игнорируются.

| Команда | Поведение прототипа |
|---|---|
| ls [аргументы...] | Выводит имя команды и полученные аргументы |
| cd [путь] | Выводит имя команды и не более одного аргумента |
| exit | Закрывает приложение |

ls и cd являются заглушками:
они не просматривают файлы и не изменяют текущую папку.

Аргумент с пробелами можно заключить в одинарные или двойные кавычки:

```text
cd "my documents"
cd 'my documents'
```

Разбор выполняется модулем shlex в режиме POSIX.
Конвейеры, перенаправления и подстановка переменных не реализованы.

## Функции программы

| Функция | Назначение |
|---|---|
| parse_command | Разбор строки с учётом кавычек |
| execute_command | Проверка команды, формирование ответа и признака выхода |
| handle_input | Получение ввода, вывод результата и закрытие окна |
| create_interface | Создание и размещение элементов интерфейса |
| submit_command | Вложенный обработчик Enter и кнопки |
| main | Создание главного окна и запуск цикла событий |

## Настройки

Настройки первого этапа задаются непосредственно в исходном коде:

- Имя VFS в заголовке: prac_vfs.
- Начальный размер окна: 800 × 500 пикселей.
- Минимальный размер окна: 400 × 200 пикселей.
- Шрифт текстовых полей: Consolas, 12 пунктов.
- MAX_CD_ARGUMENTS: максимальное число аргументов cd, равное 1.

Параметры командной строки на первом этапе не поддерживаются.

## Проверка первого этапа

Автоматические тесты пока не добавлены.
Проверка выполняется вручную в графическом интерфейсе.

| Ввод или действие | Ожидаемый результат |
|---|---|
| ls | Заглушка ls, пустой список аргументов |
| ls documents pictures | Заглушка ls, два аргумента |
| cd | Заглушка cd, пустой список аргументов |
| cd "my documents" | Один аргумент с пробелом |
| cd 'my documents' | Один аргумент с пробелом |
| cd "" | Один пустой аргумент |
| cd one two | Ошибка: слишком много аргументов |
| hello | Ошибка: неизвестная команда |
| cd "documents | Ошибка: незакрытая кавычка |
| ls после ошибки | Приложение продолжает работу |
| Пустая строка или пробелы | Ничего не выводится |
| exit extra | Ошибка, окно остаётся открытым |
| exit | Окно закрывается |

Дополнительно проверяются:

- Отправка как кнопкой, так и клавишей Enter.
- Изменение размеров окна.
- Прокрутка длинного вывода.
- Запрет редактирования области вывода.
- Отсутствие ошибок в терминале после закрытия приложения.

Ручная проверка выполнена: сценарии из таблицы пройдены,
результаты соответствуют ожидаемым.
